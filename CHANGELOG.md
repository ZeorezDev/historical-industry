# Changelog

## 0.2.0 — Industrial Expansion & Railway Logistics

- Added the rolling mill, steel plates, heavy assembly plant and industrial components to datapack production and national reports.
- Added craftable speed and efficiency modules with one recoverable upgrade slot per machine.
- Added the 54-slot warehouse, directional conveyor and reversible railway loading dock with parcel-checked transfers.
- Integrated Boxcar and Gondola cargo using Historical Railways v0.1.0's public vehicle speed and container inventory.
- Added five editable Blockbench projects, original textures, moving rollers, assembly ram and belt cleats, and English/Turkish translations.
- Kept v0.1.0's machine slot indices, world data and production history; extended the dedicated server and client asset tests.

## 0.1.0

- Added coal-fired Forge Energy generation, steelmaking, machine parts and textile production with datapack recipes.
- Bound machine operation and sided automation to verified Core industrial land.
- Added town and national daily and lifetime production reports, including a production indicator under the national economy command.
- Added English and Turkish translations and a dedicated server integration fixture.
